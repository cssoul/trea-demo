## 一、项目背景

第一版（当前仓库）是基于 **Vue 3 + Vite + D3.js（SVG）** 的储能/微电网拓扑接线图，包含：

- 编辑器（Editor.vue）：拖拽节点、连线、属性面板、组件面板、右键菜单
- 查看器（Viewer.vue）：只读展示、实时数据绑定
- 核心画布 `TopoCanvas.js`（D3 渲染、缩放平移、拖拽、连线）
- 动画 `AnimationManager.js`、数据绑定 `DataBinder.js`
- 设备类型：光伏(pv)、逆变器(pinvt)、PCS、电池堆(stack)、电池簇(cluster)、双向电表(meter)、断路器(breaker)、变压器(transformer)、充电桩(charger)、电网(grid)、母线(busbar)、直线(line)、文字、矩形框

第一版为纯 2D SVG 平面图标风格，第二版目标是 **"体素微缩（Voxel / Isometric Diorama）"立体风格**。

## 二、视觉目标（参考风格）

参考竞品视觉（微缩模型产品图风格）：

1. **设备立体化**：所有设备渲染为"微缩实物模型"效果——
   - 光伏：倾斜的深蓝色电池板阵列，带金属边框和支架
   - 逆变器/PCS：白色/灰色立体机柜，带散热格栅、指示灯、接线端子
   - 电表：带液晶显示屏（可显示读数）的立体表计
   - 电池柜：立式机柜，内部可见电池模组层叠
   - 充电桩：立式充电桩带充电枪和线缆
   - 变压器：带散热片的箱体 + 高压套管
   - 电网：输电铁塔微缩模型
   - 充电汽车、楼宇等场景元素可作为可选装饰
2. **母线/连线立体化**：从细线升级为**立体管道/汇流排**（铜排质感），带厚度、高光和阴影；通电时有**能量流动光效**（粒子/流光沿路径流动，方向和速度映射实际功率）。
3. **整体场景感**：浅色纯净背景 + 柔和地面阴影，设备像摆放在微缩沙盘上；等轴测（Isometric）视角，光照统一（左上主光 + 环境光）。
4. **实时数据可视化**：设备表面可显示屏幕/指示灯，颜色与数值随实时数据变化（如电表液晶读数、电池 SOC 电量条、故障红色告警呼吸灯）。

## 三、技术选型建议

| 项 | 推荐方案 | 备选方案 |
|---|---|---|
| 框架 | 保持 Vue 3 + Vite 不变 | — |
| 3D 渲染 | **Three.js**（正交相机 + 等轴测投影，最贴近体素微缩风格） | TresJS（Vue3 生态，声明式）、Babylon.js |
| 交互层 | 保留现有 D3 编辑器逻辑，把渲染层替换/叠加为 Three.js 画布 | 纯 Three.js 重写（raycaster 拾取 + 自实现拖拽） |
| 设备模型 | 低多边形（Low-poly）几何体拼装（代码内建，无外部资源依赖，体素感强、加载快） | GLTF 微缩模型（Poly Pizza / Sketchfab 免费资源，或 Blender 自制导出） |
| 管线/流光 | Three.js TubeGeometry + ShaderMaterial 流光着色器 | 曲线粒子系统（Points + 自定义更新） |
| 后期效果（可选） | UnrealBloomPass 轻量辉光（流光、指示灯更酷） | 不加后期，保证性能 |
| UI | 保持 ant-design-vue | — |

> 取舍说明：几何体拼装方案无需任何模型文件、包体小、风格统一，最符合"体素微缩"审美；若追求照片级真实感再引入 GLTF。两者可共存（模型加载器作为增强）。

## 四、功能需求

1. **保留第一版全部交互能力**：编辑器拖拽/连线/属性/保存加载 JSON；查看器缩放平移/弹窗/实时数据。
2. **渲染升级**：节点用 3D 设备模型渲染，母线与连线用 3D 管道渲染，等轴测视角可微调（限制在一定角度范围，保持接线图可读性）。
3. **能量流动画**：连线按功率方向/大小渲染流光（方向、速度、颜色可全局配置：粗细、默认色、充电/放电流光色，持久化到 localStorage；断路器分闸时流光停止）。
4. **设备状态渲染**：运行（绿色指示）、待机（灰）、告警（橙/红呼吸）、离线（半透明/暗化）；电表屏幕显示实时读数（CanvasTexture）。
5. **数据结构兼容**：第一版保存的 JSON 拓扑数据需可被第二版加载渲染（节点坐标映射为地面平面坐标，y 轴自动为 0）。
6. **性能**：50+ 设备、100+ 连线场景下稳定 60fps；实例化渲染（InstancedMesh）用于重复元素。

## 五、非功能需求

- 代码风格：4 空格缩进、单引号、语句末分号、函数 JSDoc 中文注释、复杂逻辑行内中文注释
- 命名：文件/变量小驼峰，Vue 组件大驼峰
- 错误处理：try-catch 包裹，console 详细日志 + 用户友好提示
- Three.js 相关代码独立成 `core/three/` 模块，与 D3 逻辑层解耦，方便维护
